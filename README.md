# Ed25519 公钥与签名校验

攻击者把公钥换成一个特殊的小阶点，签名校验对任意消息都返回通过：这类输入不应被接受。公钥必须是曲线上的合法点且不是小阶点，签名标量必须落在合法区间，编码必须最短且规范，校验必须拒绝可延展编码，消息哈希必须按声明算法，批量校验中的各签名必须互相独立。系统的不变量是：任何小阶点公钥都被拒绝，同一签名只有一种合法编码。

## 接口

提供点解码、小阶点判定、标量解码、编码规范性检查、消息哈希、单签名校验、策略校验和批量校验接口。

## 测试

在仓库根目录运行 `python -m pytest tests -q`。公开测试描述上述契约，隐藏测试用于独立验收。

## 依赖

运行时仅使用 Python 标准库，测试使用 pytest。
